# Electric-Vehicle-Population-Analysis-Predictive-Modelling-Using-Machine-Learning
Analysed 300,142 electric vehicle records using Python and five machine learning algorithms. Performed EDA, data preprocessing, outlier detection, regression, and classification to predict electric range and classify BEVs and PHEVs. Evaluated models using accuracy, precision, recall, F1-score, MAE, RMSE, and R².
